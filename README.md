# ПДД Беларусь

Нативное приложение для Android по Правилам дорожного движения Республики Беларусь — **учебная редакция с 1 сентября 2025 года**.

## Обучение, тренировка и контроль

- 12 структурированных конспектов с ключевыми тезисами;
- 62 авторских вопроса с пояснением и ссылкой на норму;
- **40 фиксированных генерируемых билетов**, по 10 вопросов;
- тренировка по главам, темам, билетам и случайным вопросам;
- **экзамен ×10**: 10 вопросов, 10 минут, не более одной ошибки;
- **контроль ×20**: 20 вопросов, 20 минут, не более двух ошибок;
- решение «вслепую» с сообщением «Ответ принят»;
- «плавающий» порядок вариантов ответа в контрольных режимах;
- полоса номеров для перехода между вопросами;
- работа над ошибками, избранное и поиск;
- локальная статистика и отметки прочитанных разделов;
- Android 8.0 (API 26) и новее.

В версии 1.2.0 шапка и номера вопросов закреплены сверху, панель «Назад / Далее» — снизу над системной навигацией. Вопрос, варианты ответа и пояснение прокручиваются в отдельной области, поэтому длинный текст не скрывает кнопки.

Механика режимов ориентирована на «Тест ПДД Беларуси» и учебную программу «Новый поворот»: короткие билеты ×10, тренировка/контроль, ограничение ошибок и просмотр ошибок. Проект не связан с ООО «Новый поворот», не копирует его графические материалы и не выдаёт генерируемые билеты за официальные билеты ГАИ.

> Вопросы являются авторскими учебными заданиями, а не официальными билетами ГАИ. Конспекты не заменяют полный текст нормативного акта. Перед практическим применением спорной нормы сверяйтесь с официальным источником.

## Обновление из приложения

Release-версия при запуске проверяет `update.json` в последнем GitHub Release. Проверку можно также запустить вручную: **Профиль → Обновление приложения**.

При наличии новой версии приложение:

1. показывает номер версии и список изменений;
2. загружает APK по HTTPS с индикатором прогресса — **без браузера**;
3. проверяет SHA-256, имя пакета и рост `versionCode`;
4. сравнивает сертификат APK с сертификатом установленного приложения;
5. передаёт проверенный APK системной службе `PackageInstaller.Session` и обрабатывает её результат.

Обычное Android-приложение не может молча установить APK. Поэтому при первом обновлении система попросит разрешить **«Установку из неизвестных источников»**, а затем покажет стандартное подтверждение установки. Это системные экраны Android, не браузер. Постоянный ключ сохраняет локальный прогресс при обновлении.

Учебные материалы работают офлайн. Интернет используется только для проверки и загрузки обновлений и при открытии пользователем внешней ссылки на официальный текст. Аккаунта, рекламы и аналитики нет. Подробности: [`UPDATES.md`](UPDATES.md).

## Сборка

Требуются JDK 17 и Android SDK 35. Версия читается из `version.properties`.

```bash
./gradlew lintRelease :app:assembleRelease :app:bundleRelease
```

Результаты:

- `app/build/outputs/apk/release/app-release.apk` — подписанный APK для установки и обновлений;
- `app/build/outputs/bundle/release/app-release.aab` — подписанный Android App Bundle.

Проверка учебного контента без Android SDK:

```bash
python3 scripts/validate_content.py
```

## GitHub Actions и публикация обновления

Workflow [`.github/workflows/android-release.yml`](.github/workflows/android-release.yml) проверяет контент и Wrapper, запускает Lint, собирает APK/AAB, сверяет сертификат и выкладывает артефакты на 90 дней.

Для нового публичного обновления:

1. увеличьте `versionCode` и `versionName` в `version.properties`;
2. обновите `RELEASE_NOTES.md`;
3. отправьте изменения в `main` или рабочую `arena/*` ветку — workflow сам возьмёт тег `vX.Y.Z` из `versionName` и опубликует релиз. Можно также использовать тег Git или ручной запуск с `publish_release=true`.

Workflow опубликует APK, AAB и `update.json` в GitHub Release. Скрипт `scripts/create_update_metadata.py` сам рассчитывает SHA-256 APK и URL скачивания. Приложение видит только самый новый публичный нечерновой релиз.

Скачать текущую сборку также можно из **Actions → Android release → Artifacts**.

## Постоянный ключ

Release-подпись находится в `signing/pdd-release.p12`, параметры — в `keystore.properties`. Один и тот же ключ используется всеми последующими сборками, поэтому обновления устанавливаются поверх предыдущей версии. Подробности и отпечаток: [`signing/README.md`](signing/README.md).

**Предупреждение:** размещение приватного ключа и пароля в репозитории выполнено по требованию проекта. Для публичного репозитория это небезопасно; используйте GitHub Secrets и защищённую резервную копию, но не меняйте ключ между релизами.

## Структура

```text
app/src/main/assets/content.json       # редакция, темы, вопросы, пояснения
app/src/main/java/by/pdd/study/        # нативный UI, билеты и контрольные режимы
app/src/main/java/by/pdd/study/data/   # JSON-репозиторий и локальный прогресс
app/src/main/java/by/pdd/study/update/ # загрузка, проверка APK и системный установщик
app/src/main/java/by/pdd/study/ui/     # компоненты, иконки и индикаторы
scripts/validate_content.py            # проверки целостности контента
scripts/create_update_metadata.py      # update.json и SHA-256
signing/                               # постоянная release-подпись
.github/workflows/android-release.yml  # CI, артефакты и GitHub Release
```

Приложение написано на Java без сторонних runtime-библиотек. Обновление читается из приватной папки приложения и передаётся напрямую системной службе `PackageInstaller`, без поиска Activity по Intent.

## Учебник и справочник знаков

Учебная часть вынесена из `content.json` в отдельный офлайн-ассет `app/src/main/assets/textbook.json`.
Вопросы, билеты и прогресс остаются в прежнем формате, поэтому существующие данные не теряются.

- 33 раздела: 27 глав ПДД, пять приложений и разбор изменений 2025 года;
- 170 уроков с нормой, разбором и четырьмя ключевыми правилами в каждом;
- 220 карточек дорожных знаков всех семи групп с значением и практическим пояснением;
- каталог знаков доступен с экрана «Учебник» и через общий поиск.

Исходники учебника поддерживаются в `scripts/textbook_*.py`. После правок пересоберите ассет и проверьте его:

```bash
cd scripts && python3 generate_textbook.py && cd ..
python3 scripts/validate_content.py
```
