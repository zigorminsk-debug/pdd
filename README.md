# ПДД Беларусь

Нативное офлайн-приложение для Android по Правилам дорожного движения Республики Беларусь — **учебная редакция с 1 сентября 2025 года**.

## Возможности

- 12 структурированных конспектов с ключевыми тезисами;
- 62 авторских тренировочных вопроса с пояснением и ссылкой на норму;
- отдельный разбор изменений Указа № 295 от 04.08.2025;
- тренировка по темам, смешанный тест и вопрос дня;
- тренировочный экзамен: 20 вопросов, 20 минут, зачёт от 90%;
- работа над ошибками, избранное, поиск по правилам и вопросам;
- локальная статистика и отметки прочитанных разделов;
- работа без интернета, аккаунта, рекламы и аналитики;
- Android 8.0 (API 26) и новее.

> Вопросы являются авторскими учебными заданиями, а не официальными билетами ГАИ. Конспекты не заменяют полный текст нормативного акта. Перед практическим применением спорной нормы сверяйтесь с официальным источником.

## Правовая основа

- Указ Президента Республики Беларусь от 28.11.2005 № 551, Правила дорожного движения: <https://pravo.by/document/?guid=12551&p0=P30500551>
- Указ Президента Республики Беларусь от 04.08.2025 № 295, изменения с 01.09.2025: <https://pravo.by/document/?guid=12551&p0=P32500295>
- Официальная публикация и краткий перечень нововведений: <https://pravo.by/novosti/novosti-pravo-by/2025/august/89729/>

В контенте отражены, среди прочего: новый статус СПМ, ограничения 10/25 км/ч и массы 35 кг, спешивание велосипедистов и водителей СПМ, садоводческие товарищества как жилая зона, мотоблоки, маркировка зимних шин и покрытия задней полусферы легкового автомобиля.

## Сборка

Требуются JDK 17 и Android SDK 35.

```bash
./gradlew lintRelease :app:assembleRelease :app:bundleRelease
```

Результаты:

- `app/build/outputs/apk/release/app-release.apk` — подписанный APK для установки;
- `app/build/outputs/bundle/release/app-release.aab` — подписанный Android App Bundle.

Проверка учебного контента без Android SDK:

```bash
python3 scripts/validate_content.py
```

## GitHub Actions

Workflow [`.github/workflows/android-release.yml`](.github/workflows/android-release.yml) запускается при push, pull request и вручную. Он:

1. проверяет JSON-контент и Gradle Wrapper;
2. запускает Android Lint;
3. собирает release APK и AAB постоянным ключом;
4. проверяет SHA-256 отпечаток сертификата подписи;
5. выкладывает оба файла в артефакты workflow на 90 дней.

Скачать APK можно из завершённого запуска **Actions → Android release → Artifacts**. Для установки на телефоне разрешите установку из выбранного источника.

## Постоянный ключ

Release-подпись находится в `signing/pdd-release.p12`, параметры — в `keystore.properties`. Один и тот же ключ используется всеми последующими сборками, поэтому обновления устанавливаются поверх предыдущей версии. Подробности и отпечаток: [`signing/README.md`](signing/README.md).

**Предупреждение:** размещение приватного ключа и пароля в репозитории выполнено по требованию проекта. Для публичного репозитория это небезопасно; используйте GitHub Secrets и защищённую резервную копию, но не меняйте ключ между релизами.

## Структура

```text
app/src/main/assets/content.json       # редакция, темы, вопросы, пояснения
app/src/main/java/by/pdd/study/        # нативный UI и навигация
app/src/main/java/by/pdd/study/data/   # JSON-репозиторий и локальный прогресс
app/src/main/java/by/pdd/study/ui/     # компоненты, иконки и индикаторы
scripts/validate_content.py            # проверки целостности контента
signing/                               # постоянная release-подпись
.github/workflows/android-release.yml  # CI и артефакты
```

Приложение написано на Java без сторонних runtime-библиотек. Разрешение `INTERNET` не запрашивается; внешние ссылки на Pravo.by открываются в браузере пользователя.
