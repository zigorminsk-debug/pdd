# Постоянная подпись релиза

- Контейнер: `pdd-release.p12` (PKCS#12, RSA 4096).
- Alias: `pdd-belarus`.
- Параметры: `../keystore.properties`.
- Срок действия сертификата: до 22 марта 2054 года.
- SHA-256 отпечаток записан в `certificate-info.txt` и проверяется в GitHub Actions после сборки.

**Не меняйте и не создавайте заново этот ключ при обновлениях.** Тот же ключ необходим Android для обновления уже установленного APK без удаления приложения и потери локального прогресса.

Ключ и пароль намеренно находятся в репозитории по требованию владельца проекта. Это удобно для доверенного частного репозитория и воспроизводимых сборок, но **небезопасно для публичного репозитория**: любой получивший файлы сможет подписать APK тем же сертификатом. Для публичной разработки перенесите PKCS#12 и пароли в GitHub Secrets, сохранив резервную копию и тот же ключ для последующих версий.
